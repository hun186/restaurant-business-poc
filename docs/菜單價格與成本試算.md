# 餐廳好管家：參照 AI 菜單的食材歷史價格與菜品成本

參考 [menu-planner](https://github.com/hun186/menu-planner) 的 [歷史價格資料](https://github.com/hun186/menu-planner/blob/main/src/menu_planner/db/repo.py)、[成本預覽](https://github.com/hun186/menu-planner/blob/main/src/menu_planner/db/admin_cost_preview.py) 與 [成本特徵](https://github.com/hun186/menu-planner/blob/main/src/menu_planner/engine/features.py)。

## 已實作的 PoC v3
- SQLite ingredient_prices：按食材／門市／生效日保留單價、供應商、來源與參照單號；金額以整數新臺幣分保存。
- 核准叫貨驗收及主管直接進貨可選填單價，價格與庫存流水寫入同一交易；無單價時不假設免費。
- menu_dishes 共用菜品及售價、dish_ingredients 每份食材配方；僅業主可調整全店共用菜品和配方。
- 依各門市截至當日的最後有效價格、每份食材用量及公斤／公克、公升／毫升換算估算材料成本、材料毛利額與比率。缺價、缺配方或單位不合時不計算成本與毛利。
- 最新單價乘庫存量僅為估算庫存價值，並非 FIFO／移動平均會計存貨成本。
- v2→v3 前先建立驗證過的 SQLite 升級備份，升級後自動備份指紋納入價格和配方。
- 門市主管只能讀寫授權門市價格、檢視授權門市成本；員工不能讀取採購價和毛利。
