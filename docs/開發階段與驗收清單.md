## 正式上線前不可跳過

- [ ] 決定是單店本機或多門市遠端使用（會影響 DB 與權限邊界）
- [ ] HTTPS、網路分層、Secure Cookie、代理主機信任設定及安全測試
- [ ] 資料庫與備份權限、可用性、資料保留年限及緊急停用程序
- [ ] 權限矩陣與測試帳號全量 E2E：員工／主管／業主，跨店與異常輸入
- [ ] 操作稽核獨立安全保存、遮蔽個資與下載稽核
- [ ] Windows 或預計部署 OS 的實機安裝、斷電及復原驗收
- [ ] 個資與勞務資料的法令及公司政策符合性審查

以上為設計／實作分期，不把「規劃」或「僅在本機通過測試」描述為正式可交付上線。
