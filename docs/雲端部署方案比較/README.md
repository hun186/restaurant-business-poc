# 餐飲管理系統：雲端部署與免費方案比較

本資料集將「餐廳好管家」從 Vercel 虛構資料展示站，轉成可保存正式資料的營運系統，所需的架構決策整理為一份完整 Word 文件與兩張資訊海報。

## 文件

- [專業分享文件（Word）](./餐飲管理系統雲端部署_專業分享文件.docx)：系統現況、資料持久化、Vercel 商業使用限制、Cloudflare Workers＋D1、Oracle Cloud、Cloudflare Tunnel 及正式營運驗收。
- [橫式資訊海報（3840 × 2160 PNG）](./餐飲管理系統雲端部署_橫式資訊海報.png)：多方案整體比較與雲端架構。
- [直式資訊海報（2400 × 3000 PNG）](./餐飲管理系統雲端部署_直式資訊海報.png)：由問題、方案與限制逐步說明正式部署決策。

## 重要說明

- **Vercel Demo 不等於正式營運系統**：目前獨立的 Demo 使用虛構資料，正式 SQLite 後端仍需另外部署或改造。
- Cloudflare Workers＋D1 是長期雲端化的候選方案，**尚未完成改造及正式部署**；既有本機 Node.js＋SQLite 不可直接原封不動搬至 D1。
- Oracle Always Free 或自有主機＋Cloudflare Tunnel 能較多沿用現有程式，但仍有主機維運、可用性、資安與備份責任。
- 免費額度、商業使用條款和價格會變動。資料主要基於 **2026-10-24** 的方案評估，正式決策時應重新核對各平台官方文件。
- 此處三份成果是技術研究分享資料，**不是系統已通過生產環境驗收的聲明**，不含業主或員工真實營運資料。
